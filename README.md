# 章雨馨｜AI 应用产品经理作品集

章雨馨的 AI 应用产品经理作品集。站点使用原生 HTML、CSS 和 JavaScript 构建，不依赖境外字体、框架、图标库或运行时 CDN。

已确认的内容、个人设计偏好、项目事实与保密边界统一记录在 [`MAINTENANCE.md`](./MAINTENANCE.md)，后续修改以该文档为依据。

## 当前内容

- 深色编辑式视觉系统与电影式滚动叙事；
- Cielo 主案例：用户需求、连续性、主动性、多 Agent 协作、用户边界、真实运行截图与 02:06 竖屏演示；
- 省级政务大模型效果优化案例：脱敏重构的评测闭环、合成测试案例、公文与安全产品链路；
- 教育信息化 SaaS 案例：跨模块业务关系、脱敏原型、验证与回归流程；
- Product Method、Experience、Education & Honors、About 和 Contact；
- 桌面端、移动端与 `prefers-reduced-motion` 适配。

宠爱家详情页及 About 个人照片仍待补充材料后制作。

## 本地预览

直接打开 `index.html` 即可浏览。建议使用最新版 Chrome、Edge 或 Safari，并在桌面端体验悬停、聚焦与滚动交互。

- `index.html`：作品集首页；
- `cases/cielo.html`：Cielo 个人智能体；
- `cases/government-llm.html`：省级政务大模型效果优化；
